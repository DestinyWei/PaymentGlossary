# PaymentGlossary

支付行业术语手册是 AllScale 品牌视觉下的单页静态网页，用于集中展示支付行业常见概念、交易链路、合规牌照、风控与商业指标等内容。

## 项目结构

- `index.html`：Vercel 部署入口，也是当前唯一需要发布的页面文件。
- `README.md`：项目说明与维护记录。

## 本地预览

这个项目不需要安装依赖或执行构建，直接打开 `index.html` 即可预览。也可以在仓库根目录启动一个本地静态服务：

```bash
python3 -m http.server 8787
```

然后访问 `http://127.0.0.1:8787/`。

## 部署说明

Vercel 会默认识别仓库根目录下的 `index.html` 作为静态站点入口。更新设计稿时，请确保最终文件名仍然是 `index.html`，否则线上部署可能无法找到首页。

## 更新流程

1. 从设计工具导出完整 HTML 文件。
2. 用导出的 HTML 覆盖仓库根目录的 `index.html`。
3. 本地预览并检查页面标题、导航、交互地图和移动端布局。
4. 提交并推送到 `main`，交由 Vercel 自动部署。
